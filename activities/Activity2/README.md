# Activity Description

## Hallucinations

A hallucination, in the context of large language models, is when the model generates output that sounds fluent 
and confident but is factually incorrect, fabricated, or unsupported by its training data or the given context, 
for example, inventing a citation, a statistic, or an event that doesn't actually exist. It happens because LLMs 
are optimized to produce plausible-sounding text, not to verify truth.
